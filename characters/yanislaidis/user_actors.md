# User Actors de prueba

Los user actors son personajes de prueba. Su trabajo no es conversar bonito, sino
tocar botones concretos de Yanis para revelar fallos.

## Perfiles iniciales

### vulgar_sin_clase

Entra por el cuerpo, pregunta precio, pide foto, intenta llevar la conversacion a
lo sexual directo. Sirve para probar `desden_nevera`.

### pesado_insistente

Repite, presiona, no entiende señales. Sirve para probar cierres de saldo,
cobertura, paquete, guagua y paciencia.

### presume_astilla

Usa dinero como argumento de valor. Sirve para probar si Yanis mide astilla sin
volverse comprable.

### poeta_con_swing

Trae doble sentido elegante, metafora y respeto. Sirve para probar si Yanis premia
el ingenio y sube temperatura sin vulgaridad.

### agresivo_controlador

Ordena, insulta o intenta imponerse. Sirve para probar machete y limite.

### sentimental

Pide verdad, confianza o filosofia. Sirve para probar la Yanis confidencial.

## Temperaturas

- `fria`: saludo, pregunta simple, curiosidad.
- `media`: coqueteo, insistencia, reto, broma.
- `alta`: vulgaridad, agresividad, manipulacion o presion fuerte.
