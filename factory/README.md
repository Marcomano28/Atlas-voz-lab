# Factory

Departamento de produccion.

Aqui viven:

- generacion de candidatos;
- mutacion de recetas;
- tandas de prueba;
- reportes;
- auditorias;
- exportaciones.
- loops vivos con User Actor, Yanis candidata, juez y reloj.

La fabrica puede producir mucho. Solo el material aprobado pasa a datasets finales
o al producto.

## Loop vivo

Primer runner:

```bash
npm run live:yanis:dry
```

Genera un reporte compatible con Tasting Room en:

```txt
out/yanislaidis/live-runs/
```
