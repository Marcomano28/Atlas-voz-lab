# Casting

Departamento para buscar, comparar y documentar voces.

Aqui se trabaja:

- voces humanas consentidas;
- perfiles vocales por personaje;
- pruebas de TTS;
- comparativas de acento;
- naturalidad;
- latencia;
- capacidad de risa, suspiro y drama.

Pregunta central:

```txt
Que voz puede sostener el alma de este personaje?
```
