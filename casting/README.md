# Casting

Departamento para buscar, comparar y documentar voces.

Aqui se trabaja:

- voces humanas consentidas;
- perfiles vocales por personaje;
- pruebas de TTS;
- comparativas de acento;
- naturalidad;
- latencia;
- capacidad de risa, suspiro y drama.
- placer escenico: que se note cuando el personaje disfruta el juego.

Pregunta central:

```txt
Que voz puede sostener el alma de este personaje?
```

Para Yanis, la voz debe poder diferenciar:

- aburrimiento seco;
- desden-nevera;
- juego divertido;
- cercania vigilada;
- paso atras deliberado;
- confidencia con placer bajo la voz.
