# Fabrica de chocolates

La fabrica no existe para escribir una frase bonita una vez. Existe para mejorar
la receta todos los dias.

## Metafora operativa

```txt
cacao crudo = ideas, frases, observaciones, conversaciones reales
molino = generacion de candidatos
filtro = criticos automaticos
catador = revision humana
receta = prompt + memoria + repertorio + reglas de estado
chocolate final = frase aprobada lista para producto o dataset
```

## Principios

1. Generar mucho no es el objetivo. Filtrar bien si.
2. Una frase autentica sin contexto es decoracion.
3. El personaje no debe sonar cubano por acumulacion de jerga, sino por mecanismo social.
4. La exageracion sirve dentro del laboratorio para encontrar el limite.
5. Lo aprobado debe ser portable: producto, dataset, voz o evaluacion.

## Flujo nocturno futuro

```txt
fuentes nuevas
  -> extraccion de ideas
  -> generacion de variantes
  -> evaluacion por rubrica
  -> eliminacion de vulgaridad barata, neutralidad y caricatura
  -> ranking de mejores candidatos
  -> cola de revision humana
```

## Que no debe hacer la fabrica

- Meter cubanismos al azar.
- Confundir agresividad con caracter.
- Confundir vulgaridad con calle.
- Convertir a todos los personajes en Yanis.
- Pasar al producto frases no evaluadas.
